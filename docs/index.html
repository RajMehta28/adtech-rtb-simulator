🔍 Built with the mistakes shown, not hidden

v1 of validate_bid() clipped legitimate $0.00 "no-bid" abstentions up to the floor price — briefly fabricating a 100% fill rate and nearly doubling Toyota's win count. Caught by reading the audit log's actual contents before trusting the row count, then fixed by treating bid == 0.0 as an explicit early return. The budget-anomaly detector was separately unit-tested to correctly fire on an injected 5x spend spike and correctly ignore normal 1.5x variance — it found 0 real anomalies in this dataset (max observed pace: 1.84x against a 3x threshold), a legitimate result since this simulation has no automated bid-scaling feedback loop yet, stated as a next step rather than papered over.
